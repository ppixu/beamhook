# Security policy

If you find a security vulnerability in Beamhook, please [report it privately on GitHub](https://github.com/ppixu/beamhook/security/advisories/new). This sends your report directly to the maintainer. Please keep vulnerability details out of public issues.

Include the Beamhook version, your macOS version, the steps that led to the problem, and the impact you observed. If you attach logs or screenshots, remove any credentials or personal information first.
