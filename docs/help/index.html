Browser setup and per-app volume help

Each browser needs one setting turned on before Beamhook can control a single tab.

Firefox tabs aren't supported. Browser controls work in Safari, Chrome, Brave, Arc and Vivaldi.

Beamhook controls apps like Spotify with AppleScript. Browsers need one more step: to see which tabs are playing and control the one you picked, Beamhook runs a small script in each tab. Browsers block this until you allow it.

Until then, media keys still reach the browser, but macOS picks the tab. That's what the notice in Beamhook means. Turning it on takes a few seconds.

Safari

1. Show the developer settings

Open Safari → Settings (⌘,), click Advanced, and tick Show features for web developers. This adds a Developer tab to Settings.

2. Allow JavaScript from Apple Events

Open the new Developer tab. Under Automation, tick Allow JavaScript from Apple Events. No restart needed.

On older versions of Safari

Older versions have no Developer tab. Step 1 adds a Develop menu to the menu bar instead, and Allow JavaScript from Apple Events is in that menu. It's the same setting either way.

Chrome

Choose View → Developer → Allow JavaScript from Apple Events. A checkmark means it's on.

The other browsers

  • Brave and Arc: same as Chrome, View → Developer → Allow JavaScript from Apple Events.
  • Vivaldi: Vivaldi → Settings → Privacy. Or search Settings for Apple Events.

After you turn it on

  • The first time Beamhook talks to the browser, macOS asks if Beamhook may control it. Click OK. If you missed it, go to System Settings → Privacy & Security → Automation → Beamhook.
  • Open Beamhook again. The notice is gone, and the playing tabs are listed instead. Hook a tab and the media keys go to it.
  • The setting is per browser and stays on until you turn it off.
  • It doesn't give websites anything. It lets apps you've allowed under Automation run JavaScript in your tabs. Beamhook uses it to see what's playing and to play, pause and change volume.

Volume and mute controls

Each app has a volume slider and a speaker button to mute it. A browser's main row sets the whole browser; the indented rows under it are single tabs. Raising a muted source's volume unmutes it, and unmuting brings back the old level.

Per-app volume and mute need macOS 14.2 or later and System Audio Recording permission. Audio is adjusted as it plays and never saved. If an app has its own volume control, Beamhook uses it. Tab controls also need the browser setting and Automation access above.

The expanded overlay

With the menu's Volume keys toggle off, press Command + Volume or Command + Play to open the app and tab picker. If a Beamhook overlay is already showing, Command + an arrow key opens it too.

  • Command + Up/Down: select a source.
  • Command + Left/Right: adjust its volume.
  • Command + Play: play or pause the selected source.
  • Command + Mute: mute or restore it.
  • Command + H: hook the selected app or tab.

With Volume keys on, the plain volume keys open the picker, and the shortcuts work without Command while it's open. Command + Volume then always changes system volume. With the toggle off, the picker closes when you let go of Command; with it on, it fades when you stop using it. Play buttons only appear for sources that support them, and for browser tabs.

Which apps appear?

The menu lists apps that are playing or played in the last two hours, plus the hooked one. Click Show all to see the rest. Paused browser tabs stay listed for up to two hours, at most three per browser. Closed tabs drop off on the next check, and the list resets when Beamhook quits.

The speaker arcs animate while sound plays. How many arcs you see follows the volume setting, not how loud the sound is.
