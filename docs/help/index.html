Browser setup and per-app volume help

A one-time switch, per browser, so Beamhook can hook your keys to one specific tab.

Firefox tab and playback control is not supported. Beamhook's browser controls work with Safari, Chrome, Brave, Arc and Vivaldi.

Beamhook controls a native app like Spotify with a single AppleScript command. Browsers work differently: to see which tabs are playing — and to send play/pause to the one you picked — Beamhook asks the browser to run a small piece of JavaScript in each tab. macOS ships with that ability turned off.

Without it your media keys still reach the browser; macOS just decides for itself which tab hears them. That's what the notice in Beamhook is telling you. Turning it on takes about twenty seconds.

Safari

1. Reveal the developer settings

Choose Safari → Settings (⌘,), click Advanced, and tick Show features for web developers. This is what puts the Developer tab in the Settings toolbar.

2. Tick the box

A Developer tab now sits at the right-hand end of the Settings toolbar, after Advanced. Open it and tick the third box under Automation: Allow JavaScript from Apple Events. That's it — no restart, no reload.

On older versions of Safari

Before the Developer tab existed, the same switch lived in the menu bar: step 1 added a Develop menu, and Allow JavaScript from Apple Events sat inside it. If your Settings window has no Developer tab, look there instead — it's one setting either way, so ticking it in one place ticks it in the other.

Chrome

In the menu bar, choose View → Developer → Allow JavaScript from Apple Events. A checkmark means it's on. There's nothing to switch on first.

The other browsers

  • Brave and Arc — same path as Chrome: View → Developer → Allow JavaScript from Apple Events.
  • Vivaldi — it lives in Vivaldi's own settings instead of a menu: Vivaldi → Settings → Privacy. Typing Apple Events into the search box at the top of Settings jumps straight to it.

After you turn it on

  • The first time Beamhook talks to the browser, macOS asks whether Beamhook may control it. Choose OK. If you dismissed that prompt, you can grant it later under System Settings → Privacy & Security → Automation → Beamhook.
  • Open the Beamhook menu again. Where the notice was, you'll now find a list of the tabs that are playing, and the keys follow whichever one you pick.
  • The switch stays on until you turn it off, and it's per browser — turning it on in Safari does nothing for Chrome.
  • It doesn't hand anything to websites. It lets applications you've already allowed under Automation run JavaScript in your tabs — Beamhook uses it to read what's playing and to send play, pause and volume.

Volume and mute controls

Each app has a volume slider and a speaker button for mute. A browser's main row controls the whole browser; indented rows control individual tabs. Raising the volume of a muted source unmutes it. Muting remembers the previous level so you can restore it.

Per-app volume and mute require macOS 14.2 or later and System Audio Recording permission. Audio is processed live and never stored. Native app controls remain in use where available. Browser-tab controls also require the JavaScript and Automation permissions described above.

The expanded overlay

With the menu's Volume keys toggle off, press Command + Volume or Command + Play to open the app-and-tab selector. While a regular Beamhook overlay is visible, Command plus an arrow opens it too.

  • Command + Up/Down: select a source.
  • Command + Left/Right: adjust its volume.
  • Command + Play: play or pause the selected source.
  • Command + Mute: mute or restore it.
  • Command + H: hook the selected app or tab.

Turn Volume keys on to open the selector with plain volume keys and use these shortcuts without Command while it is visible. In this mode, Command + Volume always controls system volume. With the toggle off, releasing Command closes the selector; with it on, the selector fades after inactivity. Playback controls appear only for sources that support them, and browsers show playback controls on their tabs.

Which apps appear?

The compact lists show apps producing sound or heard within the last two hours, plus the hooked source. Choose Show all in the menu to see other available apps. Recently played browser tabs remain available after pausing for up to two hours, with up to three shown per browser. Closed tabs disappear on the next scan; this history clears when Beamhook quits.

Animated speaker arcs indicate activity. Their number follows the volume setting, with at least one animated arc when sound is detected; they are not a live loudness meter.
